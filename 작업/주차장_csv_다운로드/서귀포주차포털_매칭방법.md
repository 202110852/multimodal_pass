# 서귀포 주차포털 매칭 방법

전국주차장정보표준데이터(서귀포 CSV)와  
[서귀포시 주차포털](https://parking.seogwipo.go.kr/parking/search) 공영주차장 데이터를 1:1로 연결하는 방식만 정리한다.

관련 스크립트: [`enrich_seogwipo_portal.py`](enrich_seogwipo_portal.py)

---

## 1. 데이터 출처

| 구분 | 내용 |
| --- | --- |
| CSV | `제주특별자치도_서귀포시_주차장정보.csv` (113곳) |
| 포털 UI | https://parking.seogwipo.go.kr/parking/search |
| 요금안내 UI | https://parking.seogwipo.go.kr/parking/fee/info |
| 포털 API | `GET https://parking.seogwipo.go.kr/api/parking/realtime/list` |

- 포털은 Vue SPA라 HTML에 목록이 없고, **realtime list API**에 주차장 마스터·요금·좌표가 함께 온다.
- API에 나오는 곳은 유료·혼합 운영 공영 위주 (**31곳**). 무료만 있는 공영은 CSV에만 있는 경우가 많다.

---

## 2. 매칭 전처리 (이름 정규화)

양쪽 주차장명에 동일하게 적용:

1. 괄호 안 부가설명 제거 — 예: `(공작물)`, `(서홍동주민센터 북서측)`
2. 공백 제거
3. `공영` 제거
4. `주차빌딩` → `주차장` 통일

예시:

| 원본 | 정규화 |
| --- | --- |
| `동홍1공영주차빌딩` | `동홍1주차장` |
| `동홍1 공영주차빌딩` | `동홍1주차장` |
| `천지공영주차빌딩(공작물)` | `천지주차장` |

토큰은 정규화 문자열에서 `한글 덩어리` + `숫자`를 뽑고, `주차장`·`노외`는 비교에서 제외한다.

---

## 3. 점수 매칭 (낮을수록 우선)

CSV 한 행 × 포털 한 곳마다 점수·사유를 계산한다.  
좌표 거리는 하버사인(m).

| 우선순위 | 조건 | reason | 비고 |
| ---: | --- | --- | --- |
| 1 | 정규화 이름 완전 일치 | `name_exact` | 거리만 tie-break |
| 2 | 한쪽 이름이 다른 쪽에 포함 | `name_contains` | **거리 ≤ 250m** 일 때만 인정 |
| 3 | 토큰 교집합 ≥ 2 **그리고** 거리 ≤ 200m | `token+coord:…` | |
| 4 | 토큰 교집합 ≥ 2 **그리고** 거리 ≤ 250m | `token:…` | |
| 5 | 이름 유사 없이 거리 ≤ 60m | `coord_only` | 오매칭 위험 → 로그 확인 |

포함 매칭에 거리 상한을 둔 이유:  
`서호`처럼 짧은 지명이 다른 이름에 섞이면 1km 이상 떨어진 곳으로 붙을 수 있음  
(예: `대륜서호…` ↔ `서호 노외1` 오매칭을 이 규칙으로 차단).

---

## 4. 1:1 확정

1. (점수, CSV id, 포털 id) 후보를 점수 오름차순 정렬
2. 앞에서부터 고르되 **CSV id·포털 parkingId 각각 한 번만** 사용
3. `coord_only` 이면서 거리 > 80m 이면 스킵

결과적으로 포털 31곳이 CSV 31행에 매칭되고, 나머지 CSV 82행은 `unmatched`.

## 5. 실측 결과 (파일럿)

| 항목 | 값 |
| --- | ---: |
| 포털 | 31 |
| CSV | 113 |
| 매칭 | 31 |
| 미매칭 포털 | 0 |
| 대부분 매칭 사유 | `name_exact` |

수동 확인 권장:

- `국토교통인재개발원 동측 공영주차장` ↔ `서호 노외1 공영주차장` (`coord_only`, 약 18m) — 명칭은 다르고 좌표만 가까움
- `정방 노외공영주차장` ↔ `정방 노외1 공영주차장` (`coord_only`, 약 23m)

## 6. 매칭 후 필드 매핑 (참고)

매칭이 확정된 뒤에만 포털 값을 CSV에 반영한다.

| 포털 필드 | CSV / 부가 컬럼 |
| --- | --- |
| `parkingId`, `parkingName` | `sgp_parking_id`, `sgp_parking_name` |
| `lat`, `lng` | `sgp_lat`, `sgp_lng` |
| `parkingAmountInfoList[].startTm~endTm` (WEEK/SAT/HOLI) | 평일·토·공휴일 운영시각 (**유료 구간**) |
| `startTm=endTm=00:00` | 해당 요일 유료 없음(무료) → 개방 00:00~23:59 유지 + 특기사항 |
| `freeTm` | `sgp_free_tm`, 특기사항 회차 면제 |
| `dfltTm` / `dfltAmt` | 주차기본시간 / 주차기본요금 |
| `intvlTm` / `intvlAmt` | 추가단위시간 / 추가단위요금 |
| `dayParkingAmt` | 1일주차권요금 |
| `periodTicketAmt` | 월정기권요금 |
| `handicapCellCount` > 0 | `장애인전용주차구역보유여부=Y` |
| `cellCount` | 주차구획수 |

요금안내 페이지 공통 문구(회차 30분 면제, 기본 1,000원 등)는 해석 참고용이고,  
주차장별 수치는 API를 우선한다.

---

## 7. 실행

```bash
python3 작업/주차장_csv_다운로드/enrich_seogwipo_portal.py
```

출력 CSV의 `sgp_match_status` / `sgp_match_reason` / `sgp_match_distance_m` 로  
매칭 성공·사유·거리를 다시 확인할 수 있다.
