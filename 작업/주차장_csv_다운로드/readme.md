## 제주시 모두의주차장 보강 (유료) — 재구현 가이드

크롤 코드·상세 시행착오는  
[`네이버지도 크롤링/주차장/readme.md`](../../네이버지도%20크롤링/주차장/readme.md)  
에 두고, **이 폴더에는 원본·결과 CSV와 실행 요약**을 둔다.

### 목표

원본 제주시 CSV의 **요금정보=유료** 이고 위·경도가 있는 행(~110건)만  
모두의주차장 정보 탭 양식으로 보강한 CSV를 **이 폴더에 저장**.

### 확정 절차 (3단계)

1. **모두의주차장**에서 이름/주소/좌표로 매칭 → 상세(정보 탭) 수집  
2. **실패하면 네이버지도**(플레이스)에서 매칭 → 같은 양식 컬럼으로 매핑  
3. 결과는 **모두의주차장 양식 컬럼**으로 `작업/주차장_csv_다운로드/` 에 저장

### 실행

```bash
# 의존성
pip3 install playwright pygeohash
python3 -m playwright install chromium

# 전체 (유료 ~110건, modu → 실패 시 naver)
python3 "네이버지도 크롤링/주차장/crawl_jeju_paid.py" --no-resume

# 일부 시험
python3 "네이버지도 크롤링/주차장/crawl_jeju_paid.py" --limit 10 --no-resume
```

중단 후 이어하기: `--no-resume` 없이 다시 실행 (`제주시_모두의주차장_done_ids.txt` 기준).

### 결과 CSV 컬럼

**메타**

- `주차장관리번호`, `원본_주차장명`, `원본_도로명`, `원본_지번`, `원본_위도`, `원본_경도`, `원본_요금정보`
- `match_status` (`success` / `needs_confirm` / `fail`)
- `match_source` (`modu` / `naver`)
- `match_step`, `match_message`
- `modu_seq`, `modu_name`, `matched_site_url`, `tried_queries`

**모두의주차장 정보 탭 양식**

| 컬럼 | Modu UI / JSON |
| --- | --- |
| `운영 시간` | 요약 (`openFree.operationTime`) |
| `현장 요금` | 예: `1시간 기준 2,000원` |
| `주소` | `newAddress` (도로명) |
| `초기무료` | 요금 안내 · 시간요금 |
| `기본요금` | 요금 안내 · 시간요금 |
| `추가 요금` | 요금 안내 · 추가요금 |
| `할증 기준시간` | 요금 안내 |
| `운영시간_평일` | 유료 운영시간 · 평일 |
| `운영시간_토요일` | 유료 운영시간 · 토요일 |
| `운영시간_일요일` | 유료 운영시간 · 일요일 |
| `운영시간_공휴일` | 유료 운영시간 · 공휴일 |
| `추가정보` | 예: `장애인`, `기계식` (`options`) |

### 110건 실행 요약 (2026-09-10)

| 구분 | 건수 |
| --- | ---: |
| 대상 (유료+좌표) | 110 |
| modu success | 104 |
| modu needs_confirm | 5 |
| naver 폴백 success | 1 |

주소는 전건 채움. 현장 요금·초기무료 등 상세 요금안내는 Modu에 있는 곳만 채워짐(나머지 `정보 없음`/공란).
