# 카카오맵 REST API — 장소 검색

> 원문: [카카오맵 > REST API](https://developers.kakao.com/docs/ko/kakaomap/rest-api)

인증:

```http
Authorization: KakaoAK ${REST_API_KEY}
```

응답 형식(`FORMAT`): `json`(기본) 또는 `xml`

검색 범위는 중심 좌표+반경(`x`, `y`, `radius`) 또는 사각형(`rect`)으로 지정할 수 있습니다.

## 1. 키워드로 장소 검색

| 메서드 | URL | 인증 |
| --- | --- | --- |
| `GET` | `https://dapi.kakao.com/v2/local/search/keyword.${FORMAT}` | REST API 키 |

요청한 키워드에 부합하는 장소 검색 결과를 지정한 정렬 기준으로 반환합니다.

### 요청 — 쿼리 파라미터

| 이름 | 타입 | 설명 | 필수 |
| --- | --- | --- | --- |
| query | `String` | 검색 질의어 | O |
| category_group_code | `CategoryGroupCode` | 카테고리로 결과 필터링 | X |
| x | `String` | 중심 좌표 X (경도). `radius`와 함께 사용 | X |
| y | `String` | 중심 좌표 Y (위도). `radius`와 함께 사용 | X |
| radius | `Integer` | 검색 반경 (0~20000 m). **중심 좌표 필수** | X |
| rect | `String` | 사각형 범위 `좌측X,좌측Y,우측X,우측Y` | X |
| page | `Integer` | 페이지 (1~45, 기본 1) | X |
| size | `Integer` | 페이지당 장소 수 (1~15, 기본 15) | X |
| sort | `String` | `accuracy`(기본) / `distance` (**`distance` 시 x,y 필수**) | X |

### 응답

**Meta**

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| total_count | `Integer` | 검색된 장소 수 |
| pageable_count | `Integer` | 노출 가능 장소 수 |
| is_end | `Boolean` | 마지막 페이지 여부 |
| same_name | `SameName` | 지역·키워드 분석 정보 |

**SameName**

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| region | `String[]` | 검색어에서 인식된 지역 목록 |
| keyword | `String` | 지역을 제외한 키워드 |
| selected_region | `String` | 현재 검색에 사용된 지역 |

**Document**

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| id | `String` | 장소 ID |
| place_name | `String` | 장소명, 업체명 |
| category_name | `String` | 카테고리 이름 |
| category_group_code | `String` | 주요 카테고리 그룹 코드 (없으면 `""`) |
| category_group_name | `String` | 주요 카테고리 그룹명 (없으면 `""`) |
| phone | `String` | 전화번호 |
| address_name | `String` | 전체 지번 주소 |
| road_address_name | `String` | 전체 도로명 주소 |
| x | `String` | 경도 |
| y | `String` | 위도 |
| place_url | `String` | 장소 상세 페이지 URL |
| distance | `String` | 중심 좌표까지 거리(m). 요청에 x,y 포함 시만 |

### 예제 — 강남구 삼성동 20km 반경 카카오프렌즈

```bash
curl -v -G GET "https://dapi.kakao.com/v2/local/search/keyword.json" \
  -H "Authorization: KakaoAK ${REST_API_KEY}" \
  --data-urlencode "query=카카오프렌즈" \
```

## 2. 카테고리로 장소 검색

| 메서드 | URL | 인증 |
| --- | --- | --- |
| `GET` | `https://dapi.kakao.com/v2/local/search/category.${FORMAT}` | REST API 키 |

요청한 카테고리 코드에 해당하는 장소 검색 결과를 지정한 정렬 기준으로 반환합니다.

### 요청 — 쿼리 파라미터

| 이름 | 타입 | 설명 | 필수 |
| --- | --- | --- | --- |
| category_group_code | `CategoryGroupCode` | 카테고리 그룹 코드 | O |
| x | `String` | 중심 좌표 X (경도) | X |
| y | `String` | 중심 좌표 Y (위도) | X |
| radius | `Integer` | 검색 반경 (0~20000 m). **중심 좌표 필수** | X |
| rect | `String` | 사각형 범위 `좌측X,좌측Y,우측X,우측Y` | X |
| page | `Integer` | 페이지 (1~45, 기본 1) | X |
| size | `Integer` | 페이지당 개수 (1~15, 기본 15) | X |
| sort | `String` | `accuracy`(기본) / `distance` (**`distance` 시 x,y 필수**) | X |

### 응답

키워드 검색과 동일한 `meta` / `documents` 구조를 사용합니다.  
`same_name`은 없을 경우 `null`입니다.  
`category_group_code` / `category_group_name`은 요청한 카테고리 값이 그대로 반환됩니다.

### 예제 — 강남구 삼성동 20km 반경 약국

```bash
curl -v -G GET "https://dapi.kakao.com/v2/local/search/category.json" \
  -H "Authorization: KakaoAK ${REST_API_KEY}" \
  -d "category_group_code=PM9" \
  -d "y=37.514322572335935" \
  -d "x=127.06283102249932" \
  -d "radius=20000"
```
