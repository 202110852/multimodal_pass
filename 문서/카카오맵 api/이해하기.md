# 카카오맵 API — 이해하기

> 원문: [카카오맵 > 이해하기](https://developers.kakao.com/docs/ko/kakaomap/common)

이 문서는 카카오맵 API를 소개합니다.

## 기능 소개

카카오맵 API는 웹과 앱 서비스에서 위치 기반 데이터를 조회하는 **REST API**와, 카카오맵을 표시하고 제어하는 **지도 SDK**를 제공합니다. 데이터 조회와 지도 기능 구현에 사용할 수 있는 기능 목록은 [제공 방식](#제공-방식)에서 확인할 수 있습니다.

## 제공 방식

카카오맵 API는 REST API와 지도 SDK 두 가지 방식으로 제공합니다.

### REST API

REST API는 장소, 주소, 좌표, 경로와 같은 데이터를 조회하거나 지도 이미지를 생성하는 기능을 제공합니다. 지번 주소와 도로명 주소 체계를 모두 지원합니다. 전체 API 규격은 [REST API 문서](https://developers.kakao.com/docs/ko/kakaomap/rest-api)에서 확인할 수 있습니다.

| 구분 | 제공 기능 |
| --- | --- |
| 주소/좌표 변환 | 주소와 좌표 변환, 좌표계 변환 |
| 장소 검색 | 키워드 및 카테고리 기반 장소 검색 |
| 경로 조회 | 출발지와 도착지 좌표 기준 대중교통, 도보, 자전거 경로 조회 |
| 정적 지도 조회 | 지정한 좌표와 옵션 기반 정적 지도 이미지 생성 |

### 지도 SDK

지도 SDK는 웹과 모바일 애플리케이션에서 카카오맵을 표시하고 제어하는 기능을 제공합니다. 개발 문서·레퍼런스·샘플은 Kakao Maps API 웹사이트에서 확인할 수 있습니다.

| 구분 | 사용 환경 | 사용 플랫폼 키 | 참고 |
| --- | --- | --- | --- |
| 지도 Web(JavaScript) SDK | 웹 서비스에서 카카오맵 지도 기능 구현 | JavaScript 키 | [지도 Web SDK 개발 문서](https://apis.map.kakao.com/web/guide/) |
| 지도 Android SDK | Android 앱에서 카카오맵 지도 기능 구현 | 네이티브앱 키 | [지도 Android SDK 개발 문서](https://apis.map.kakao.com/android_v2/docs/) |
| 지도 iOS SDK | iOS 앱에서 카카오맵 지도 기능 구현 | 네이티브앱 키 | [지도 iOS SDK 개발 문서](https://apis.map.kakao.com/ios_v2/docs/) |

**지도 SDK 플랫폼 키**

지도 SDK로 API 호출 시, 반드시 지정된 종류의 플랫폼 키를 사용해야 합니다. 지도 SDK에 REST API 키를 사용하지 않도록 주의합니다. 잘못된 앱 키 사용 시 에러가 발생합니다.

→ [지도_SDK.md](./지도_SDK.md)

## 사용 방법

카카오맵 API를 사용하려면 아래 작업을 수행해야 합니다.

1. [카카오디벨로퍼스](https://developers.kakao.com/) 앱 생성
2. 카카오맵 API 활성화: 앱 관리 페이지의 **[카카오맵] > [사용 설정]**의 **[상태]**를 **[ON]**으로 설정
   - 개발자 계정 기준 **첫 번째로** 카카오맵 API를 활성화한 앱에만 무료 쿼터 제공 (참고: [무료 쿼터 적용 앱 확인](#무료-쿼터-적용-앱-확인))
3. 카카오맵 REST API 사용 시, 사용할 REST API 키에 필요한 설정 등록
4. 카카오맵 지도 SDK 사용 시 플랫폼별 지정된 플랫폼 키에 아래 정보 등록
   - Web(JavaScript) SDK: JavaScript 키의 JavaScript SDK 도메인
   - Android/iOS SDK: 네이티브 앱 키의 Android/iOS 앱 정보
5. 아래 조건에 하나라도 해당하는 경우, **비즈월렛 연결 후 유료 API 사용 설정** 필요
   - 개발자 계정 기준 첫 번째로 활성화한 앱이 아닌 앱(두 번째 활성화 앱부터)에서 카카오맵 API를 사용하는 경우
   - 앱 활성화 순서와 관계없이 무료 쿼터를 초과해 사용해야 하는 경우

### 무료 쿼터 적용 앱 확인

카카오맵 API를 개발자 계정 기준 첫 번째로 활성화해 무료 쿼터를 제공받는 앱은, 앱 정보에 **[카카오맵 무료 쿼터]** 뱃지가 표시됩니다.

> **카카오맵 API 사용 방법 변경**  
> 2026년 7월 21일부터 카카오맵 API 사용 방법과 무료 쿼터 제공 방식이 변경되었습니다. 자세한 안내는 [공지](https://developers.kakao.com/docs/ko/kakaomap/common)를 참고합니다.

## 이용 정책

### 쿼터

카카오 API는 원활한 서비스 제공을 위해 월간 및 일간 쿼터(Quota)를 적용합니다. 현재 적용 중인 무료 쿼터 정보는 [무료 제공 쿼터](https://developers.kakao.com/docs/ko/getting-started/quota)에서 확인할 수 있습니다.

카카오맵 API는 개발자 계정 기준 **첫 번째로 활성화한 앱에만 무료 쿼터를 제공**합니다. 첫 번째로 활성화한 앱이 아닌 앱(두 번째 활성화 앱부터) 또는 무료 쿼터를 초과해 사용해야 하는 경우, 비즈월렛 연결 및 유료 API 사용 설정 후 사용량 기반 과금으로 이용할 수 있습니다.

→ 상세: [쿼터_이용정책.md](./쿼터_이용정책.md)

## FAQ

### Q. 429 Too Many Request 에러가 발생해요.

카카오맵 API는 앱별로 무료로 제공하는 쿼터가 있습니다. 무료 제공량을 모두 소진한 경우, 429 에러가 발생합니다.

무료 제공량 외에 더 많은 제공량이 필요한 경우, [유료 API](https://developers.kakao.com/docs/ko/app-setting/paid-api)를 설정해 추가 API를 호출할 수 있습니다.

### Q. 내가 사용한 쿼터 사용량은 어디서 확인할 수 있나요?

앱 관리 페이지의 **[통계] > [쿼터]**에서 내 앱이 사용한 월간 및 일간 쿼터를 확인할 수 있습니다.

### Q. 카카오맵 API 사용 시 활용할 수 있는 카카오맵 아이콘 이미지가 있나요?

네. **[도구] > [리소스 다운로드] > [카카오맵]**에서 카카오맵 로고와 디자인 가이드를 제공합니다. 카카오맵 API를 활용하는 서비스나 바로가기 아이콘으로 사용할 수 있습니다.

로고 사용 시, 사용자에게 일관된 브랜드 이미지를 전달하기 위해 디자인 가이드를 준수하는 것을 권장합니다.

### Q. 카카오맵 API에 대해 궁금한 점이 있어요. 어디로 문의하면 되나요?

[데브톡의 카카오맵 API 게시판](https://devtalk.kakao.com/)의 게시글을 찾아보거나, 서비스 소유자나 관계자로 확인되는 계정으로 글을 남기면 담당자가 빠르게 대응할 수 있습니다.

## 제공 API 목록

아래 표는 REST API 문서에서 제공하는 API 목록입니다. 지도 SDK의 플랫폼별 API는 Kakao Maps API 웹사이트에서 확인합니다.

각 API의 Kakao SDK 지원 여부는 [지원 범위](https://developers.kakao.com/docs/ko/getting-started/support)에서 확인할 수 있습니다.

### 주소 / 좌표 변환

| API | 메서드 | URL | 설명 |
| --- | --- | --- | --- |
| 주소로 좌표 변환 | `GET` | `https://dapi.kakao.com/v2/local/search/address.${FORMAT}` | 요청한 문자열 주소의 좌표와 세부 정보를 반환합니다. |
| 좌표로 행정구역정보 변환 | `GET` | `https://dapi.kakao.com/v2/local/geo/coord2regioncode.${FORMAT}` | 지정한 좌표값에 해당하는 행정동과 법정동 정보를 반환합니다. |
| 좌표로 주소 변환 | `GET` | `https://dapi.kakao.com/v2/local/geo/coord2address.${FORMAT}` | 지정한 좌표값에 해당하는 지번 주소와 도로명 주소 정보를 반환합니다. |
| 좌표계 변환 | `GET` | `https://dapi.kakao.com/v2/local/geo/transcoord.${FORMAT}` | 특정 좌표계의 좌표값을, 지정한 좌표계의 좌표값으로 반환합니다. |
