# 카카오맵 REST API — 경로 조회

> 원문: [카카오맵 > REST API](https://developers.kakao.com/docs/ko/kakaomap/rest-api)

인증:

```http
Authorization: KakaoAK ${REST_API_KEY}
```

무료 일간 쿼터: 각 경로 API **1,000건/일** (첫 번째 활성화 앱 기준). 상세는 [쿼터_이용정책.md](./쿼터_이용정책.md) 참고.

> 자동차(차량) 길찾기는 카카오맵 REST API가 아니라 [카카오모빌리티 길찾기 API](../카카오모빌리티%20길찾기%20api/README.md)를 사용합니다.

---

## 1. 대중교통 경로 조회

| 메서드 | URL | 인증 |
| --- | --- | --- |
| `GET` | `https://dapi.kakao.com/v2/routing/publictraffic` | REST API 키 |

지정한 출발지와 도착지 좌표의 대중교통 경로를 반환합니다.

### 요청 — 쿼리 파라미터

| 이름 | 타입 | 설명 | 필수 |
| --- | --- | --- | --- |
| start_x | `String` | 출발지 X 좌표 | O |
| start_y | `String` | 출발지 Y 좌표 | O |
| s_name | `String` | 출발지 명칭 (기본: `출발`) | X |
| end_x | `String` | 도착지 X 좌표 | O |
| end_y | `String` | 도착지 Y 좌표 | O |
| e_name | `String` | 도착지 명칭 (기본: `도착`) | X |
| input_coord | `String` | `WGS84`(기본) / `WTM` / `TM` / `WCONGNAMUL` | X |
| output_coord | `String` | `WGS84`(기본) / `WTM` / `TM` / `WCONGNAMUL` | X |

### 응답 — 본문

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| status | `String` | `OK` / `STARTNODES_NULL` / `ENDNODES_NULL` / `EQUAL_POINTS` / `INVALID_REQUEST` / `NO_RESULTS` |
| properties | `Properties` | 경로 조회 결과 속성 |
| routes | `Route[]` | 경로 목록 (`status`가 `OK`일 때만) |

**Properties**

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| total | `Integer` | 전체 경로 수 |
| bus | `Integer` | 버스 경로 수 |
| subway | `Integer` | 지하철 경로 수 |
| busAndSubway | `Integer` | 버스+지하철 경로 수 |
| landingURL | `String` | 카카오맵 길찾기 랜딩 URL |

**RouteProperties**

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| type | `String` | `BUS` / `SUBWAY` / `BUS_AND_SUBWAY` |
| totalDistance | `Integer` | 거리 (m) |
| totalTime | `Integer` | 소요 시간 (초) |
| transfers | `Integer` | 환승 횟수 |
| fare | `Fare` | 요금 (`value` / `min` / `max`, 원) |

**StepProperties**

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| guidance | `String` | 안내 문구 |
| type | `String` | `BUS` / `SUBWAY` / `WALKING` |
| distance | `Integer` | 거리 (m) |
| time | `Integer` | 시간 (초) |
| stops | `Stop[]` | 정류장 목록 (`name`) |
| vehicles | `Vehicle[]` | 차량 (`type`, `name`) |

**Path**

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| points | `Double[][]` | `[x, y]` 좌표 쌍 목록 |

### 예제

```bash
curl -v -G GET "https://dapi.kakao.com/v2/routing/publictraffic" \
  -H "Authorization: KakaoAK ${REST_API_KEY}" \
  --data-urlencode "start_x=127.11119217" \
  --data-urlencode "start_y=37.39477123" \
  --data-urlencode "end_x=127.12628814" \
  --data-urlencode "end_y=37.41993056"
```

```json

    {
      "properties": {
        "type": "BUS",
```

## 2. 도보 경로 조회

| 메서드 | URL | 인증 |
| --- | --- | --- |
| `GET` | `https://dapi.kakao.com/v2/routing/walk` | REST API 키 |

지정한 출발지와 도착지 좌표의 도보 경로를 반환합니다. 경유지 최대 5개.

### 요청 — 쿼리 파라미터

| 이름 | 타입 | 설명 | 필수 |
| --- | --- | --- | --- |
| start_x | `String` | 출발지 X | O |
| start_y | `String` | 출발지 Y | O |
| via_x | `String` | 경유지 X (최대 5개, `,` 구분) | X |
| via_y | `String` | 경유지 Y (최대 5개, `,` 구분) | X |
| end_x | `String` | 도착지 X | O |
| end_y | `String` | 도착지 Y | O |
| s_name | `String` | 출발지 명칭 (기본: `출발`) | X |
| v_name | `String` | 경유지 명칭 (최대 5개, `,` 구분) | X |
| e_name | `String` | 도착지 명칭 (기본: `도착`) | X |
| input_coord | `String` | `WGS84`(기본) / `WTM` / `TM` / `WCONGNAMUL` | X |
| output_coord | `String` | `WGS84`(기본) / `WTM` / `TM` / `WCONGNAMUL` | X |
| route_mode | `String` | `BROAD_FIRST`(기본, 넓은 길 우선) / `SHORTEST` / `ACCESSIBLE` | X |

### 응답 — 본문

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| status | `String` | `OK` / `SAME_POINT` / `START_LINK_NOT_FOUND` / `END_LINK_NOT_FOUND` / `TOO_MANY_SEARCH_LINK` / `TOO_FAR_AWAY` / `ROUTE_RESULT_NOT_FOUND` |
| route | `Route` | 전체 경로 (`status`가 `OK`일 때만) |

**RouteProperties**

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| totalDistance | `Integer` | 전체 거리 (m) |
| totalTime | `Integer` | 전체 시간 (초) |
| landingUrl | `String` | 카카오맵 길찾기 랜딩 URL |

**구조**: `route.legs[].steps[]`  
각 step: `properties`(`distance`, `guidance`, `time`, `x`, `y`) + `path.points`

### 예제

```bash
curl -v -G GET "https://dapi.kakao.com/v2/routing/walk" \
  -H "Authorization: KakaoAK ${REST_API_KEY}" \
  --data-urlencode "start_x=127.11119669891646" \
  --data-urlencode "start_y=37.394776627382875" \
  --data-urlencode "end_x=127.12629039752096" \
  --data-urlencode "end_y=37.4199323570413"
```

```json
{
  "status": "OK",
  "route": {
    "properties": {
      "totalDistance": 4025,
      "totalTime": 3914,
      "landingUrl": "https://map.kakao.com/link/by/walk/..."
    },
    "legs": [
      {
        "properties": { "distance": 4025, "time": 3914 },
        "steps": [
          {
            "properties": {
              "distance": 93,
              "guidance": "판교역 1번 출구까지 역사 내 이동",
              "time": 84,
              "x": 127.11119783,
              "y": 37.39477573
            },
            "path": {
              "points": [
                [127.11119783, 37.39477573],
                [127.11119779, 37.39474869]
              ]
            }
          }
        ]
      }
    ]
  }
}
```

## 3. 자전거 경로 조회

| 메서드 | URL | 인증 |
| --- | --- | --- |
| `GET` | `https://dapi.kakao.com/v2/routing/bicycle` | REST API 키 |

지정한 출발지와 도착지 좌표의 자전거 경로를 반환합니다. 경유지 최대 5개.

### 요청 — 쿼리 파라미터

도보 경로와 동일하되 `route_mode`만 다릅니다.

| 이름 | 타입 | 설명 | 필수 |
| --- | --- | --- | --- |
| route_mode | `String` | `BIKE_ONLY`(기본, 자전거도로 우선) / `SHORTEST` / `ACCESSIBLE` | X |

나머지 파라미터: `start_x/y`, `via_x/y`, `end_x/y`, `s_name`, `v_name`, `e_name`, `input_coord`, `output_coord`

### 응답

도보 경로 조회 API 응답과 동일합니다.

### 예제

```bash
curl -v -G GET "https://dapi.kakao.com/v2/routing/bicycle" \
  -H "Authorization: KakaoAK ${REST_API_KEY}" \
  --data-urlencode "start_x=127.11119669891646" \
  --data-urlencode "start_y=37.394776627382875" \
  --data-urlencode "end_x=127.12629039752096" \
  --data-urlencode "end_y=37.4199323570413"
```
