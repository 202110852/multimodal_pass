# 카카오맵 REST API — 정적 지도 조회

> 원문: [카카오맵 > REST API](https://developers.kakao.com/docs/ko/kakaomap/rest-api)

인증:

```http
Authorization: KakaoAK ${REST_API_KEY}
```

| 메서드 | URL | 인증 |
| --- | --- | --- |
| `GET` | `https://dapi.kakao.com/v2/maps/staticmap` | REST API 키 |

지정한 좌표와 옵션을 반영한 정적 지도 이미지를 생성해 반환합니다.

무료 일간 쿼터: **1,000건/일** (첫 번째 활성화 앱 기준).

## 카카오 CI 로고

- 응답 이미지에 카카오 CI 로고가 포함됩니다.
- `logo_pos`로 위치는 조정할 수 있으나 **제거는 불가**합니다.

## 요청 — 쿼리 파라미터

| 이름 | 타입 | 설명 | 필수 |
| --- | --- | --- | --- |
| center | `String` | 지도 중심 좌표 `X,Y` (예: `127.1105,37.3955`) | X* |
| markers | `String` | 마커 정보 (아래 형식) | X* |
| size | `String` | 이미지 크기 `{WIDTH}x{HEIGHT}` (최대 `2048x1024`) | O |
| format | `String` | `png`(기본) / `jpg` | X |
| logo_pos | `String` | `BOTTOM_LEFT`(기본) / `BOTTOM_RIGHT` / `TOP_LEFT` / `TOP_RIGHT` | X |
| scale | `Integer` | `1` / `2`(기본). `2`이면 응답은 `size`의 2배 | X |
| lv | `Integer` | 줌 레벨 (1~15, 기본 3) | X |
| coord | `String` | `WGS84`(기본) / `WCONGNAMUL` / `WTM` / `TM` | X |

\* `center` 또는 `markers` 중 **하나 이상 필수**. 둘 다 생략하면 지도 중심을 정할 수 없어 에러가 발생합니다.

### markers 내부 파라미터

- 키·값: 콜론(`:`)으로 구분
- 파라미터 연결: 파이프(`|`)
- 마커 간 연결: 앰퍼샌드(`&`)
- 최대 **5개**

| 이름 | 타입 | 설명 | 필수 |
| --- | --- | --- | --- |
| location | `String` | 마커 좌표 `X,Y` | O |
| option | `Boolean` | 영역 자동 계산 시 마커 제외 여부 (`true`: 제외, `false`: 포함·기본) | X |

예시:

```
markers=location:127.1105,37.3955|option:false&markers=location:127.1120,37.3970|option:false
```

## 응답

- 본문: 정적 지도 이미지 **바이너리** 데이터
- `Content-Type`: `image/png` 또는 `image/jpeg` (`format`에 따름)

## 예제

```bash
curl -v -G GET "https://dapi.kakao.com/v2/maps/staticmap" \
  -H "Authorization: KakaoAK ${REST_API_KEY}" \
  --data-urlencode "center=127.1105,37.3955" \
  --data-urlencode "size=640x480" \
  --data-urlencode "markers=location:127.1105,37.3955|option:false" \
  -o map.png
```

```
HTTP/1.1 200 OK
Content-Type: image/png
<binary image data>
```
