# 카카오맵 REST API — 주소 / 좌표 변환

> 원문: [카카오맵 > REST API](https://developers.kakao.com/docs/ko/kakaomap/rest-api)

인증:

```http
Authorization: KakaoAK ${REST_API_KEY}
```

응답 형식(`FORMAT`): `json`(기본) 또는 `xml`

---

## 1. 주소로 좌표 변환

| 메서드 | URL | 인증 |
| --- | --- | --- |
| `GET` | `https://dapi.kakao.com/v2/local/search/address.${FORMAT}` | REST API 키 |

요청한 문자열 주소의 좌표와 세부 정보를 반환합니다. 지번·도로명 주소 모두 지원합니다.

> **검색어에 상세 주소 제외 권장**  
> `query`에 상세 주소(지번·도로명 번호 하위 건물명 등)는 제외하고 요청할 것을 권장합니다. 상세 주소 입력 형태가 다양해 정확한 검색을 보장하기 어렵습니다.

### 요청 — 쿼리 파라미터

| 이름 | 타입 | 설명 | 필수 |
| --- | --- | --- | --- |
| query | `String` | 검색 질의어 (지번·도로명 주소) | O |
| analyze_type | `String` | `similar`(기본): 건물명 일부 매칭 시 확장 검색 / `exact`: 정확한 건물명만 | X |
| page | `Integer` | 페이지 번호 (1~45, 기본 1) | X |
| size | `Integer` | 페이지당 결과 수 (1~30, 기본 10) | X |

### 응답 — 본문

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| meta | `Meta` | 메타 정보 |
| documents | `Document[]` | 주소 검색 결과 목록 |

**Meta**

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| total_count | `Integer` | 검색된 결과 수 |
| pageable_count | `Integer` | 노출 가능 결과 수 |
| is_end | `Boolean` | 마지막 페이지 여부 (`false`면 `page` 증가 가능) |

**Document**

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| address_name | `String` | 전체 지번 또는 도로명 주소 |
| address_type | `String` | `REGION` / `ROAD` / `REGION_ADDR` / `ROAD_ADDR` |
| x | `String` | X 좌표 (WGS84이면 경도) |
| y | `String` | Y 좌표 (WGS84이면 위도) |
| address | `Address` | 지번 주소 상세 |
| road_address | `RoadAddress` | 도로명 주소 상세 |

**Address**

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| address_name | `String` | 전체 지번 주소 |
| region_1depth_name | `String` | 시도 |
| region_2depth_name | `String` | 구 |
| region_3depth_name | `String` | 동 |
| region_3depth_h_name | `String` | 행정동 명칭 |
| h_code | `String` | 행정 코드 |
| b_code | `String` | 법정 코드 |
| mountain_yn | `String` | `Y`/`N` (산 여부) |
| main_address_no | `String` | 지번 주번지 |
| sub_address_no | `String` | 지번 부번지 (없으면 `""`) |
| x, y | `String` | 좌표 |

> `zip_code`: Deprecated (6자리 우편번호)

**RoadAddress**

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| address_name | `String` | 전체 도로명 주소 |
| region_1depth_name ~ region_3depth_name | `String` | 지역 Depth |
| road_name | `String` | 도로명 |
| underground_yn | `String` | `Y`/`N` (지하 여부) |
| main_building_no | `String` | 건물 본번 |
| sub_building_no | `String` | 건물 부번 (없으면 `""`) |
| building_name | `String` | 건물 이름 |
| zone_no | `String` | 우편번호 (5자리) |
| x, y | `String` | 좌표 |

### 예제

```bash
curl -v -G GET "https://dapi.kakao.com/v2/local/search/address.json" \
  -H "Authorization: KakaoAK ${REST_API_KEY}" \
  --data-urlencode "query=전북 삼성동 100"
```

## 2. 좌표로 행정구역정보 변환

| 메서드 | URL | 인증 |
| --- | --- | --- |
| `GET` | `https://dapi.kakao.com/v2/local/geo/coord2regioncode.${FORMAT}` | REST API 키 |

지정한 좌표값에 해당하는 행정동과 법정동 정보를 반환합니다.

### 요청 — 쿼리 파라미터

| 이름 | 타입 | 설명 | 필수 |
| --- | --- | --- | --- |
| x | `Double` | X 좌표 (WGS84이면 경도) | O |
| y | `Double` | Y 좌표 (WGS84이면 위도) | O |
| input_coord | `String` | `WGS84`(기본) / `WCONGNAMUL` / `CONGNAMUL` / `WTM` / `TM` | X |
| output_coord | `String` | `WGS84`(기본) / `WCONGNAMUL` / `CONGNAMUL` / `WTM` / `TM` | X |

### 응답 — Document

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| region_type | `String` | `H`: 행정동 / `B`: 법정동 |
| address_name | `String` | 전체 지역 명칭 |
| region_1depth_name | `String` | 시도 (바다 영역이면 미포함) |
| region_2depth_name | `String` | 구 (바다 영역이면 미포함) |
| region_3depth_name | `String` | 동 (바다 영역이면 미포함) |
| region_4depth_name | `String` | 리 영역(법정동)인 경우만 존재 |
| code | `String` | 행정동/법정동 코드 |
| x, y | `Double` | 좌표 |

### 예제

```bash
curl -v -G GET "https://dapi.kakao.com/v2/local/geo/coord2regioncode.json" \
  -H "Authorization: KakaoAK ${REST_API_KEY}" \
  -d "x=127.1086228" \
```

## 3. 좌표로 주소 변환

| 메서드 | URL | 인증 |
| --- | --- | --- |
| `GET` | `https://dapi.kakao.com/v2/local/geo/coord2address.${FORMAT}` | REST API 키 |

지정한 좌표값에 해당하는 지번 주소와 도로명 주소 정보를 반환합니다.

> 지정한 좌표에 따라 도로명 주소는 반환되지 않을 수 있습니다.

### 요청 — 쿼리 파라미터

| 이름 | 타입 | 설명 | 필수 |
| --- | --- | --- | --- |
| x | `Double` | X 좌표 (WGS84이면 경도) | O |
| y | `Double` | Y 좌표 (WGS84이면 위도) | O |
| input_coord | `String` | `WGS84`(기본) / `WCONGNAMUL` / `CONGNAMUL` / `WTM` / `TM` | X |

### 응답

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| meta.total_count | `Integer` | 변환된 주소 개수 (`0` 또는 `1`) |
| documents[].address | `Address` | 지번 주소 상세 |
| documents[].road_address | `RoadAddress` | 도로명 주소 상세 |

### 예제

```bash
curl -v -G GET "https://dapi.kakao.com/v2/local/geo/coord2address.json" \
  -H "Authorization: KakaoAK ${REST_API_KEY}" \
  -d "x=127.423084873712" \
  -d "y=37.0789561558879" \
  -d "input_coord=WGS84"
```

## 4. 좌표계 변환

| 메서드 | URL | 인증 |
| --- | --- | --- |
| `GET` | `https://dapi.kakao.com/v2/local/geo/transcoord.${FORMAT}` | REST API 키 |

특정 좌표계의 좌표값을 지정한 좌표계의 좌표값으로 반환합니다.

### 요청 — 쿼리 파라미터

| 이름 | 타입 | 설명 | 필수 |
| --- | --- | --- | --- |
| x | `Double` | X 좌표 | O |
| y | `Double` | Y 좌표 | O |
| input_coord | `String` | `WGS84`(기본) / `WCONGNAMUL` / `CONGNAMUL` / `WTM` / `TM` / `KTM` / `UTM` / `BESSEL` / `WKTM` / `WUTM` | X |
| output_coord | `String` | 위와 동일 (기본 `WGS84`) | X |

### 응답 — Document

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| x | `Double` | 변환된 X |
| y | `Double` | 변환된 Y |

### 예제

```bash
curl -v -G GET "https://dapi.kakao.com/v2/local/geo/transcoord.json" \
  -H "Authorization: KakaoAK ${REST_API_KEY}" \
  -d "x=160710.37729270622" \
  -d "y=-4388.879299157299" \
  -d "input_coord=WTM" \
  -d "output_coord=WGS84"
```

```json
{
  "meta": { "total_count": 1 },
  "documents": [
    { "x": 126.57740680000002, "y": 33.453357700000005 }
  ]
}
```
