## 정책 요약

- 카카오 API는 **월간·일간 쿼터(Quota)**를 적용합니다.
- 카카오맵 API는 개발자 계정 기준 **첫 번째로 활성화한 앱에만 무료 쿼터**를 제공합니다.
- 두 번째 이후 앱이거나 무료 쿼터를 초과하면 **비즈월렛 연결 + 유료 API 사용 설정** 후 사용량 기반 과금으로 이용합니다.
- **2026년 7월 21일**부터 사용 방법·무료 쿼터 제공 방식이 변경되었습니다.

무료 쿼터를 받는 앱은 앱 정보에 **[카카오맵 무료 쿼터]** 뱃지가 표시됩니다.

## 유료 API 사용 설정

1. 앱과 **비즈월렛**을 연결합니다.
2. 앱 관리 페이지 **[유료 API] > [일반] > [사용 가능한 유료 API]**에서 카카오맵의 **[설정]**으로 유료 사용을 켭니다.
3. 무료 쿼터 소진 후 추가 호출 시 사용량 기반 과금이 적용됩니다.

유료 사용량·단가·청구 금액은 앱 관리 페이지의 유료 API 화면에서 확인할 수 있습니다.
